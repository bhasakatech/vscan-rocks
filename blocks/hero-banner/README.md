# hero-banner

Custom **hero** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Badge Column | `badge-column` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Badge Column.

## Content structure

Rows: [background image] [rich text: eyebrow, heading, copy, CTAs, price] [optional badge image].

## Usage

Page-opening hero on the homepage, specialty and product pages; also webinar promo banners.

## Reuse guidance

Use badge-column on product pages with an award badge beside the text.
