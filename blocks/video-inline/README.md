# video-inline

Custom **video** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Dark.

## Content structure

Rows: [link to video file or YouTube/Vimeo URL] [optional poster image]. Native files render with controls and the poster.

## Usage

Native product videos in blog articles and product pages.

## Reuse guidance

Use dark for the rounded dark frame. Add the autoplay class manually for a muted background loop.
